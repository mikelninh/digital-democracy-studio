# Accessibility and comprehension protocol

## Target

The public interface targets WCAG 2.2 Level AA. Automated checks are necessary but not sufficient.

## Implemented release checks

- document language and unique page title;
- skip link and semantic navigation;
- visible keyboard focus;
- labelled form controls and live result region;
- no autoplay or flashing content;
- reduced-motion support;
- touch-friendly controls;
- no dependence on colour alone;
- meaningful link text;
- no third-party font request;
- responsive layout;
- complaint and correction paths visible.

## Manual accessibility checks

Before public release:

- keyboard-only journey;
- screen-reader landmarks and form labels;
- zoom at 200% and 400%;
- reflow at narrow viewport;
- contrast verification;
- focus order and focus visibility;
- error messages and instructions;
- plain-language review.

## Comprehension test

Five or more external testers answer:

1. What is verified?
2. What is explicitly not established?
3. Does the score represent guilt?
4. What is the next action?
5. How can an affected party respond?
6. How can a reader request a correction?
7. What data must not be submitted?
8. What would count as real animal-welfare impact?

Pilot target: at least 80% correct on questions 1–7. This is a project target, not proof of universal accessibility.

## Recording

Store only consented, minimal test results. Do not collect disability or medical details unless necessary and explicitly consented.
