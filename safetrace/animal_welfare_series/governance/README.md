# Governance status — Spuren im System · Tierwohl

This directory turns the public-source alpha into a reviewable citizen-investigation workflow. It does **not** claim that external reviews or a sensitive-tip partnership already exist.

## What is implemented now

| Gap | Implemented now | Still external |
|---|---|---|
| Editorial review | versioned review packet, conflicts declaration, pass/block decision | an independent editor must actually review |
| Legal and privacy review | checklist, data-minimisation gate, naming and harm questions | qualified legal/privacy reviewer must sign off |
| Animal-welfare domain review | species, welfare and implementation checklist | independent domain expert must review |
| Moderation and complaints | complaint, correction, appeal and conflict process | enough trained moderators and published response performance |
| Source retention | public-source registry and Evidence Vault hand-off rules | original-byte backfill and independent integrity review for every source |
| Right of reply | standard questions, timing, answer log and publication hold | actual delivery and responses |
| Accessibility and comprehension | WCAG 2.2 AA target, static release checks and test script | external disabled-user and comprehension tests |
| Sensitive tips | strict NO-GO boundary and partner acceptance criteria | a named, qualified partner |

## Non-negotiable release rule

A technical green check means the files are structurally consistent. It does not replace editorial, legal, privacy, accessibility or animal-welfare judgment.

## Public alpha boundary

The public alpha accepts only cases built from already-public sources. It does not accept leaks, confidential files, private addresses, witness identities or operational criminal allegations.
