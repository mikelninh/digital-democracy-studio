Method

Every case moves through the same discipline.

The interface can change. The analytical contract should not.

01

Ask the exact question

Define what must actually be verified before collecting more material.

02

Build the source trail

Keep publisher, date, authority, exact location and entity identity attached.

03

Separate evidence from inference

Show what a source establishes, what it does not and which uncertainty remains.

04

Move the case forward

Request evidence, compare records, escalate review, correct or publish the next justified step.

Trust by design

Make the boundary visible.

SafeTrace is useful only if a reviewer can see where the evidence ends and judgement begins.

Always preserved

Evidence stays attached.

  • ✓Primary-source provenance and retrieval context.
  • ✓Open gaps, contradictions and time-bounded claims.
  • ✓Counter-evidence and correction paths.
  • ✓Human analytical and publishing authority.
Not the product

No accusation engine.

SafeTrace does not turn a red flag, sequence or model confidence into guilt. Restricted data, real victim data and consequential publication require separate authority, privacy/security controls and human review.
