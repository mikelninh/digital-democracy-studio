# Zero Suffering Intelligence — Roadmap to V1.0

Updated: 2026-08-13

## Release principle

Ship small public increments. A version number represents a user-visible capability, not a design mockup.

## Shipped

- [x] v0.1 — public front door: Impact → Power → Evidence → Change
- [x] v0.2 — clickable graph + Evidence Inspector
- [x] v0.3 — search, status filters and Path Mode
- [x] v0.4 — public Claim Ledger with stable claim IDs, source type, review state, boundaries, correction state and shareable claim hashes
- [x] v0.5 — Animal Impact Mirror alpha: multidimensional company profiles without a guilt score; PFG reviewed, Westfleisch and PHW seeded from first-party sources
- [x] v0.6 — Entity Resolution benchmark alpha: messy-name merge/separate cases with explicit merge reasoning and no silent auto-merges

## Next

- [ ] v0.7 — Investigation OS intake: URL/document → source record → extracted candidate entities/claims → human approve/reject → Claim Ledger proposal
- [ ] v0.8 — Watchtower: source-change monitoring, supersession, version history and alerts
- [ ] v0.9 — external reality test: 3 deep-dive cases challenged by external researchers/journalists; publish failures and corrections

## V1.0 release gates

V1.0 ships only when all gates below are met.

### Coverage
- [ ] 10 major organisations with reviewed public profiles
- [ ] 3 deep-dive investigations
- [ ] 100+ human-reviewed atomic public claims
- [ ] at least one fully sourced farm → intermediary → facility → legal entity → product/brand path, or an explicit published account of why the final hop remains inaccessible

### Evidence integrity
- [ ] every verified public edge resolves to a stable claim ID
- [ ] every verified claim has source URL/type, accessed date, review status and explicit boundary
- [ ] allegations, investigations, authority findings and final judgments have separate statuses
- [ ] historical/current ownership and entity names are versioned
- [ ] correction history remains visible
- [ ] right-of-reply workflow is documented and used for consequential company profiles

### Entity resolution
- [ ] 30–50 deliberately messy benchmark records
- [ ] published precision/recall/F1 on frozen benchmark
- [ ] merge evidence visible for every proposed canonicalisation
- [ ] false positives/false negatives and human corrections published
- [ ] no merge based only on same address or similar name

### Product usefulness
- [ ] Journalist test: source behind a claim reachable in <30 seconds
- [ ] Citizen test: user can understand what is known vs unknown in <2 minutes
- [ ] Fairness test: investigated party can inspect source, exact claim, boundary and correction route
- [ ] public export for claims/cases
- [ ] basic source and entity search
- [ ] responsive public interface

### Reliability / external test
- [ ] at least 3 external reviewers use the system on real questions
- [ ] failures, corrections and unresolved disputes are logged
- [ ] benchmark metrics and evidence coverage are shown alongside product claims

## V1.0 definition

**Zero Suffering Intelligence V1.0 is a public evidence infrastructure for understanding who affects animals, how power flows through the food system, what can be proven, where uncertainty remains, and where change has the highest leverage.**

It is not a guilt ranking and not an allegation engine.
